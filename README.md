
# Job & Internship Management Portal

A web-based platform designed to help students explore job and internship opportunities through a simple, organized, and user-friendly interface.

## About the Project

The Job & Internship Management Portal is a frontend web application developed to simplify the process of discovering and managing career opportunities.

Students can explore available jobs and internships, view detailed information, access application interfaces, and manage their profiles in one centralized platform.

This project focuses on frontend development using HTML and CSS, with a responsive and visually appealing design.

## Features

- Centralized job and internship listings
- User-friendly navigation bar
- Job opportunities browsing
- Internship opportunities browsing
- Detailed job and internship information
- Application interface
- Application success notification page
- Student profile page
- About page
- Responsive and organized layout
- Interactive navigation links

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layouts
- Git & GitHub – Version control and team collaboration

## Main Pages

### Home Page
Provides an overview of the portal and access to available jobs and internships.

### Jobs Page
Displays job opportunities in an organized layout with relevant information.

### Internships Page
Allows students to explore available internship opportunities.

### Details Pages
Provides detailed information about selected jobs and internships.

### Application Page

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/srivastavaachintya25-hash/Job-Internship-Management-Portal
   ```

2. Open the project folder in VS Code.

3. Open `Home/home.html` in your browser.

4. Navigate through the website using the navigation links.
