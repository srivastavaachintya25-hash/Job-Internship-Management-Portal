# Career Portal

A simple and user-friendly web-based Career Portal designed to help users explore job opportunities, internships, and career-related resources.

## Project Overview

Career Portal is a front-end website developed using HTML and CSS. It provides users with an organized platform to explore full-time jobs, internships, and career opportunities through a clean and responsive interface.

The project is developed collaboratively using Git and GitHub, allowing team members to work on different features through separate branches.

## Features

- Home page with an attractive hero section
- Job opportunities page
- Internship opportunities page
- Internship details pages
- Job details pages
- About page
- Navigation bar connecting different pages
- Career category cards
- Call-to-action sections
- Simple and user-friendly interface
- Collaborative development using Git and GitHub

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code
- Live Server
